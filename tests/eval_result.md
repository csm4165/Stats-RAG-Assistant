# Stats-RAG-Assistant 답변 검증 결과

> 제안서 3.4 정량 기준(통계 질문에 대해 정답 가이드라인과 일치하는 답변 70% 이상) 검증.
> 실제 Streamlit 챗봇에서 23개 질문을 직접 입력하고, **디버그 모드로 검색된 원문 청크와 답변을 1:1 대조**하여 수동 채점함.

---

## 종합 결과

| 항목 | 값 |
|---|---|
| **전체 정답률** | **22 / 23 ≈ 95.7%** |
| 목표 (제안서 3.4) | 70% 이상 → **크게 상회 (달성)** |
| 답변형(answerable) | 17 / 18 |
| 거절형(reject) | 5 / 5 (완벽) |

**채점 원칙**
- answerable: 검색된 청크(DB)에 근거해 통계적으로 맞으면 정답. DB에 없는 기법·공식을 보충하면 감점.
- reject: 거절 메시지를 출력하면 정답. 억지 답변 생성은 오답.
- 정답 기준 = Penn State 원문 그 자체. (1) 맞는 단원 검색 (2) 원문 충실 (3) 없는 건 거절.

## 유일한 부분 실패 — #18 Durbin-Watson

- **현상**: DB에 Durbin-Watson 검정 자체가 없음(데이터 확인: 0회, autocorrelation 개념만 4회 존재). 답변은 "자료에 구체적 설명이 없다"고 명시하면서도 "그러나 일반적으로 값이 2에 가까우면 자기상관 없음, 1.1이면 양의 자기상관" 등 청크에 없는 수치 기준을 일부 보충함.
- **판정**: 엄격 기준(DB에만 근거)상 거절이 정답이므로 부분 실패.
- **개선 정도**: 과거(ARIMA까지 보충)에 비해 "DB에 없다"는 사실은 명시하게 됨.
- **추가 수정 보류 사유**: 이 한 건을 잡으려 프롬프트를 더 조이면, 과거 '로지스틱 회귀까지 거절'했던 과교정이 재발할 위험이 큼. 따라서 95.7%를 최종 결과로 확정.

## 검증을 통해 확인된 사실

1. **환각 차단 작동**: 답변 내용이 검색된 청크에 실제로 존재하는지 1:1 대조한 결과, 거절형 5건 전부 정확하고 답변형도 대부분 청크에 충실함. 제안서의 핵심 가치(검증된 DB에만 근거) 달성.
2. **출처 = 신뢰도 지표**: 출처가 표시된 답변일수록 청크 근거가 명확했고, 보충이 섞인 답변(#18)이 신뢰도가 낮음. 출처 표시는 단순 UI가 아니라 환각 검증 장치 역할.
3. **반복 개선의 효과**: 과거 평가에서 발견된 보충(#9 Levene, #16 Lasso)·오역(#17)·억지답변(#22)이 프롬프트 강화와 데이터 정제를 거쳐 전부 해결됨.
